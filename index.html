SOBRE O JOGO

Conheça nosso desenvolvedor.

Este é um jogo integrado no site, usando JavaScript como linguagem de programação. É um jogo no estilo RPG em turnos, inspirado em jogos como Sea Of Stars, onde você deve analisar suas opções de ações para pensar no que fazer.

Nele você deve escolher entre 2 personagens para controlar, o guerreiro e o mago. Após a escolha, seu objetivo é derrotar o inimigo, que é um goblin, e depois o próximo inimigo, que é um Chefão. Você deve escolher estratégicamente o que fazer em cada turno, entre atacar, se curar ou usar suas habilidades
